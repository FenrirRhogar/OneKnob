# Third-party components

One Knob is built with the following third-party software. Their licence notices
must be retained when distributing the plugin.

## JUCE
- https://juce.com, fetched at build time (tag 8.0.13).
- JUCE is dual-licensed (AGPLv3 or a paid JUCE licence). One Knob is distributed
  under **AGPLv3**, which is JUCE's open-source option.

## VST 3 SDK
- Steinberg Media Technologies GmbH, MIT licence (bundled with JUCE). The full notice
  ships in each release as THIRD_PARTY_NOTICES.txt.

## LV2
- ISC licence (bundled with JUCE), used for the Linux LV2 build.
